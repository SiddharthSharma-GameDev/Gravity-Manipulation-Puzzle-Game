# Gravity Shift

Gravity Shift is a third-person sci-fi puzzle platformer developed in Unity.

The player must collect glowing cubes inside a futuristic gravity chamber by manipulating gravity and moving across floors, walls, and other surfaces.

## Gameplay

The player moves using WASD, jumps with Space, selects gravity direction using the arrow keys, and applies the selected gravity using Enter.

The objective is to collect all cubes within the 2-minute time limit while avoiding free fall.

## Controls

- W, A, S, D - Move
- Space - Jump
- Arrow Keys - Select gravity direction
- Enter - Apply selected gravity
- Mouse - Rotate camera
- Esc - Pause menu

## Features

- Third-person character movement
- Space key jump
- Gravity manipulation using arrow keys
- Enter key to apply selected gravity
- Hologram gravity direction preview
- Third-person camera system
- Character animations
- 2-minute countdown timer
- Cube collection objective
- Win and game over states
- Game over if time runs out
- Game over if player falls freely without surface contact
- Pause menu with resume and exit options
- Restart gameplay flow
- UI and audio polish
